Limits

A rate limit of 0 disables throttling. Worst-case memory for this instance is roughly concurrent calls × max response size.

Egress

Required when the API runs on this machine or your LAN — the Zotero desktop app included. Cloud instance-metadata addresses stay blocked regardless.

Include the port, e.g. 127.0.0.1:23119 — a bare 127.0.0.1 with no port is a different Host header and may still be rejected. Some local services check the request's Host header as a defense against DNS rebinding and reject anything but a loopback name on the exact port they listen on — Zotero's local API is one. A container reaches such a service through a different address (like host.docker.internal), which then gets rejected as the Host header unless overridden here. Leave empty unless "Test connection" fails with 400 Bad Request while a direct curl from the host machine succeeds.
