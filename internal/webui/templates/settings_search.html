Semantic search

One embedder is shared by every instance that can build a semantic-search index (Zotero, Gitea, Linkding) — configure it once here rather than per instance. Point it at a local embeddings sidecar (Ollama or text-embeddings-inference), then build or update each instance's index from that instance's own page.

Leave empty to leave semantic search off for every instance.

0 disables throttling. This budget is shared across every instance, since they all call the same embedder.
