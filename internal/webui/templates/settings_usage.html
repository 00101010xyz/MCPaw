Usage log settings

Controls the usage log — a record of MCP tool calls, separate from the audit log and its own 90-day retention. This log is capped by size instead: once it reaches the limit below, the oldest entries are deleted first to make room for new ones.

Full includes whatever a caller sent and got back, which can carry the content of a query or another connector's personal data — pick it deliberately, not by default.
